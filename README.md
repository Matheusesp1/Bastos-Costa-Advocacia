**# -Bastos-Costa-Advocacia

Este projeto consiste no desenvolvimento de um site moderno, responsivo e intuitivo, com foco em oferecer uma excelente experiência de navegação, acessibilidade e desempenho em diferentes dispositivos.

## 🚀 Tecnologias utilizadas

- React ou Next.js
- JavaScript
- HTML5
- CSS3
- Git e GitHub
- Vercel para hospedagem e deploy

## ✨ Funcionalidades

- Interface moderna e responsiva.
- Navegação intuitiva e organizada.
- Layout adaptado para dispositivos móveis, tablets e desktops.
- Código estruturado para facilitar a manutenção e futuras melhorias.

## 💻 Execução local

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd nome-do-projeto
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o ambiente de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse o endereço local informado no terminal.

## 🌐 Deploy

O projeto será publicado utilizando a Vercel, com integração ao GitHub para facilitar as atualizações e a publicação de novas versões.
